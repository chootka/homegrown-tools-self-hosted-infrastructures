Arduino → Processing

Sending data over serial to make things on screen

What is Serial Communication?

  • A way for two devices to talk to each other over a wire
  • Data is sent one byte at a time (that's the "serial" part)
  • Your Arduino already uses it — that's what Serial.println() does
  • The Serial Monitor shows you what Arduino is sending
Arduino   ——— USB cable ———>   Computer

What is Processing?

  • Free, open-source creative coding environment
  • Made for artists and designers
  • Creates a window where you draw with code
  • If you know Arduino, you already know the structure

The Big Idea

[ Physical World ] → Arduino → Serial → Processing → [ Screen ]

Sensors become visuals.

One Rule

Only one program can use the serial port at a time.

  • If the Arduino Serial Monitor is open, Processing can't connect
  • Always close the Serial Monitor before running Processing
  • If you get "port busy" — this is probably why

Part 1: Growing a Circle

1 potentiometer → circle size

Potentiometer → analogRead() → Serial.println() → USB → Processing → circle

Circuit

  • Potentiometer outer pins → 5V and GND
  • Potentiometer middle pin → A0

That's it. One component, three wires.

Arduino Code

int POT_PIN = A0;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int potValue = analogRead(POT_PIN);
  Serial.println(potValue);
  delay(50);
}

Upload this, then verify it works with the Serial Monitor. You should see numbers from 0–1023.

Processing Code — Key Parts

import processing.serial.*;   // load the serial library
Serial port;                   // our connection to Arduino

void setup() {
  size(600, 600);
  printArray(Serial.list());   // find your Arduino's port
  port = new Serial(this, Serial.list()[0], 9600);
  port.bufferUntil('\n');      // read one line at a time
}

Change the index [0] to match your Arduino in the list.

Processing Code — Receiving Data

void draw() {
  background(30);
  fill(255, 150, 0);
  noStroke();
  ellipse(width/2, height/2, circleSize, circleSize);
}

// Runs every time a line arrives from Arduino
void serialEvent(Serial p) {
  String s = p.readStringUntil('\n');
  if (s == null) return;
  int v = int(trim(s));
  circleSize = int(map(v, 0, 1023, 10, 500));
}

Try It

  2. Close the Serial Monitor
  3. Open Processing, paste the code, hit Play
  4. Turn the knob

Sending Two Values

How do we send two numbers over one serial connection?

Separate them with a comma: "512,300"

Serial.print(x);       // send x
Serial.print(",");     // send a comma
Serial.println(y);     // send y + newline

On the other side, we split() the string at the comma to get both values back.

Arduino Code — Etch A Sketch

int POT_X = A0;
int POT_Y = A1;

void setup() {
  Serial.begin(9600);
}

void loop() {
  int x = analogRead(POT_X);
  int y = analogRead(POT_Y);

  Serial.print(x);
  Serial.print(",");
  Serial.println(y);

  delay(20);
}

Processing — Parsing Two Values

void serialEvent(Serial p) {
  String s = p.readStringUntil('\n');
  if (s == null) return;
  s = trim(s);

  // "512,300" → ["512", "300"]
  String[] values = split(s, ',');
  if (values.length < 2) return;

  float newX = map(int(values[0]), 0, 1023, 0, width);
  float newY = map(int(values[1]), 0, 1023, 0, height);

  stroke(0);
  strokeWeight(3);
  line(penX, penY, newX, newY);

  penX = newX;
  penY = newY;
}

The Drawing Trick

No background() in draw().

  • In Part 1, we called background(30) every frame — erasing the old circle
  • Here, we skip it — so every line stays on screen
  • The drawing accumulates, like pen on paper

Bonus: Clear Button

  • Add a button on pin 2 (using INPUT_PULLUP)
  • When pressed, Arduino sends "CLEAR" instead of coordinates
  • Processing checks for "CLEAR" and resets the canvas
// Arduino side
if (digitalRead(BUTTON_PIN) == LOW) {
  Serial.println("CLEAR");
  delay(300);
  return;
}

// Processing side
if (s.equals("CLEAR")) {
  background(255);
  return;
}

Key Takeaways

  • Serial.println() sends data as text, one line at a time
  • Use commas to send multiple values: "x,y"
  • Use split() to take them apart on the other side
  • map() converts ranges — works in both Arduino and Processing
  • Close the Serial Monitor before running Processing
  • Physical inputs → screen visuals. That's the bridge.
